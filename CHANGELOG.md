# Changelog

Package releases are tracked with Changesets. User-facing changes for each published package are listed in its package changelog.

## 0.2.0

- Updated Chrome built-in AI types to `@types/dom-chromium-ai` 0.0.17.
- Added complete Prompt API session management, structured output, cloning, overflow compaction, and persisted chat restoration.
- Added production wrappers and interactive examples for Summarizer, Writer, Rewriter, Translator, Language Detector, and Proofreader.
- Added lifecycle-safe WebMCP registration, discovery, execution, diagnostics, and declarative form helpers.
- Added safe Markdown rendering across generated-prose components, including headings, lists, links, tables, and code blocks.
- Rebuilt the live API directory and playground pages with responsive cards, usage examples, real back navigation, and stable client-only layouts.
- Improved streaming and input performance by keeping browser sessions shallow and coalescing high-frequency rendering.
