# Support

## Questions and integration help

Use [GitHub Discussions](https://github.com/DeSource-Labs/browser-ai/discussions) for implementation questions, architecture decisions, and ideas that are not yet actionable bug reports.

## Bugs

Open a [bug report](https://github.com/DeSource-Labs/browser-ai/issues/new?template=bug_report.yml) with a reproduction and your Chrome version. Include the API availability state and enabled flags because built-in AI behavior can vary by Chrome channel, hardware, language, region, policy, and model download state.

## Feature requests

Open a [feature request](https://github.com/DeSource-Labs/browser-ai/issues/new?template=feature_request.yml). New framework packages should share behavior and terminology with the existing Vue core wherever the framework permits.

## Security and conduct

Use the private reporting paths in [SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Do not disclose sensitive reports in public issues.
